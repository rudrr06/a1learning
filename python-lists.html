Lists & Indexing

A list holds many items in order. Watch the numbered slots change as the code runs.

🐍 Try it yourself

Real Python runs right here in your browser. Try: print fruits[2], add your own fruit with append, or print fruits[-1]. Press Ctrl+Enter to run.

The first run downloads Python (about 10 MB), then runs are instant. input() is not supported here.

What just happened?

The step you are on lights up here.

  1. What is a list? – An ordered collection stored in one variable.
  2. Creating one – Items go in [ ] separated by commas. Indexes start at 0.
  3. Reading an item – list[index] gives the item in that slot.
  4. append – Adds an item at the end.
  5. len – Counts items. The last index is len - 1.
  6. Replacing – list[index] = value overwrites that slot.
  7. Negative index – -1 is the last item, -2 the one before.
  8. remove – Deletes by value; later items shift down.
  9. print – Shows the whole list.

Why it matters

Lists hold things like usernames, IP addresses, scores or lines of a log file.

Careful: asking for an index that does not exist (like fruits[10]) causes an IndexError. This "off by one" kind of mistake is behind many real bugs, including some buffer overflows in other languages.
