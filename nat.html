NAT

Every device at home has a private IP. NAT is how your router lets them all use the internet.

What just happened?

The step you are on lights up here.

  1. 1. Private to public – Devices use private IPs inside, the router has one public IP.
  2. 2. NAT table – The router remembers each connection in a table.
  3. 3. Rewrite source – The source address and port are replaced with the public ones.
  4. 4. Reply and translate back – Replies are matched to the table and sent to the correct device.
  5. 5. Unrequested traffic – Packets with no matching entry are dropped.

Why it matters

Why it exists: there are only about 4.3 billion IPv4 addresses, not enough for every device. NAT (specifically PAT, port address translation) lets a whole network share one public IP. IPv6 has enough addresses that NAT is not needed.

Port forwarding is a manual NAT rule: "send anything arriving on public port 8080 to 192.168.1.50:80". It is how you host a server at home, and also how people accidentally expose devices.

Security note: NAT hides internal addresses and drops unsolicited inbound traffic, but it is not a firewall. Malware inside can still connect out, and attackers can use port forwards, UPnP or phishing to get in.
