Dictionaries (Key → Value)

A dictionary stores pairs: a key and its value. Watch the table change line by line.

🐍 Try it yourself

Real Python runs right here in your browser. Try: add a "course" key, change the age, or print student.get("phone", "none"). Press Ctrl+Enter to run.

The first run downloads Python (about 10 MB), then runs are instant. input() is not supported here.

What just happened?

The step you are on lights up here.

  1. Key and value – Each item is a key: value pair.
  2. Creating – Use { } with key: value pairs.
  3. Lookup – dict[key] returns the value.
  4. Add – Assigning to a new key adds a pair.
  5. Update – Assigning to an existing key replaces its value.
  6. in – Checks if a key exists.
  7. get() – Safe lookup with a default.
  8. del – Deletes a key and its value.
  9. print – Shows the whole dictionary.

Why it matters

Dictionaries are everywhere: JSON from websites, settings, user records, counting how often words or IP addresses appear.

Security link: API responses and log entries are dictionaries. Analysts use them to count failed logins per IP address or to look up details by user ID.
