Variables & Data Types

A program remembers things in variables. Step through and watch the memory on the right.

🐍 Try it yourself

Real Python runs right here in your browser. Try: change the age, add a True/False variable, or print the type of each one. Press Ctrl+Enter to run.

The first run downloads Python (about 10 MB), then runs are instant. input() is not supported here.

What just happened?

The step you are on lights up here.

  1. Top to bottom – Python runs one line at a time, in order.
  2. Strings – Text in quotes is a str.
  3. Integers – Whole numbers are int.
  4. Floats – Numbers with a decimal point are float.
  5. Updating a variable – The right side is calculated first, then stored.
  6. Booleans – True or False values for decisions.
  7. print – Displays values for the user.
  8. type() – Tells you the data type.

Why it matters

Variables are the memory of every program: scores, names, prices, passwords.

Security link: scripts for scanning, log analysis and automation all start with variables. Also, never hard-code real passwords in a variable that you upload to GitHub.
