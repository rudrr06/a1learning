Sorting Lists

Put things in order: numbers, words, or by any rule you choose.

🐍 Try it yourself

Real Python runs right here in your browser. Try: sort words alphabetically, then by length, then sort names with sorted(names, key=str.lower). Press Ctrl+Enter to run.

The first run downloads Python (about 10 MB), then runs are instant. input() is not supported here.

What just happened?

The step you are on lights up here.

  1. Two ways – sorted() makes a new list; .sort() changes the original.
  2. Start – An unsorted list.
  3. sorted() – Original unchanged.
  4. reverse – reverse=True gives largest first.
  5. Original intact – Proof that sorted() copies.
  6. .sort() – Sorts in place, returns None.
  7. Changed – The list itself is now sorted.
  8. key= – A function that gives each item's sort value.
  9. Result – Ordered by length.

Why it matters

Sorting is everywhere: leaderboards, newest-first logs, alphabetical names, biggest files.

Security link: analysts sort IP addresses by number of failed logins, or log entries by time, to spot the worst offenders and the sequence of events first. A common mistake: writing nums = nums.sort() sets nums to None!
