While Loops

A rocket countdown. Watch the condition get checked again and again.

🐍 Try it yourself

Real Python runs right here in your browser. Try: start at 5, count by 2s (count = count - 2), or delete the "count = count - 1" line and watch the Stop button save you. Press Ctrl+Enter to run.

The first run downloads Python (about 10 MB), then runs are instant. input() is not supported here.

What just happened?

The step you are on lights up here.

  1. The rule – while repeats while a condition is True.
  2. Setup – Create the variable the condition uses.
  3. Check first – The condition is checked before every round.
  4. Body runs – The indented lines run.
  5. Change something – Something must change, or the loop never ends.
  6. Check again – Back to the top.
  7. Round 2 – Same pattern.
  8. Counter down – count is now 1.
  9. Round 3 – Last round.
  10. Counter 0 – Condition will fail.
  11. Exit – False → loop stops.
  12. After loop – Python carries on below the loop.

Why it matters

while is used when you wait for something: keep trying until the user enters a valid value, keep reading until a file ends, keep retrying a connection.

Security link: brute-force tools use loops to try password after password, and defenders add limits (lockouts, delays) to stop them. An infinite loop in a service can also freeze it (a denial of service).
